### 🚀 Sobre o Projeto
Sistema dedicado ao monitoramento em tempo real de hardware de consoles de máquinas de raio-X, focado em garantir a estabilidade operacional, prevenção de falhas e rastreamento de métricas críticas de desempenho para a **MINT**.
